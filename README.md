# 🗣️ Fono Care Plus
Checkpoint 3 | Mobile

## 📘 Descrição

O **Fono Care Plus** é um aplicativo desenvolvido em **React Native** para o **Checkpoint 3**.
O projeto apresenta um espaço voltado à **fonoaudiologia digital**, permitindo que o usuário selecione uma faixa etária e visualize as principais **dores e dificuldades de fala, voz e deglutição** tratadas em cada fase da vida.

---

## ⚙️ Instalação e Execução

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/usuario/FonoCarePlus.git
cd FonoCarePlus
```

### 2️⃣ Instalar dependências

```bash
npm install
```

### 3️⃣ Dependências principais

```bash
npm install @react-navigation/native
npm install @react-navigation/native-stack
npm install @react-navigation/drawer
npm install @react-navigation/bottom-tabs
npm install @react-native-picker/picker
```

### 4️⃣ Executar o app

```bash
npx react-native start
npx react-native run-android
# ou
npx react-native run-ios
```
